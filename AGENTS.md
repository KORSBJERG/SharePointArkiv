# GitHub-synkronisering

Når du afslutter en ændring for brugeren, så kør relevante tests, commitér opgavens filer, og push committen til [KORSBJERG/SharePointArkiv](https://github.com/KORSBJERG/SharePointArkiv) via branchens upstream. Kontrollér, at GitHub har modtaget committen, før du melder arbejdet færdigt. Bevar ændringer, der tilhører andre opgaver eller brugeren selv.

Hold lokale indstillinger, certifikater, private nøgler, logfiler og Windows-builds uden for Git. Brug `config.example.json` til eksempler med fiktive værdier.
